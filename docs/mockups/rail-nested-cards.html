Nested cards — your live rail

Variation B (accent stripe) pane cards nested inside a per-worktree body card. Repo is a section label, not a third card — triple nesting would be too much.

Three surface levels

bg-0 rail tray · bg-1 group body card · bg-2 pane card. Each step lighter = each level reads as "on top of" the last.

State = left stripe

working · needs-input (pulses) · done (pulses + faint tint) · idle (dim). Read peripherally — no dot to hunt for.

New at-a-glance context

Model badge + context_pct now surface on every Claude card; ctx goes amber >60%, red >80% (see anthology-type-conversion at 95%, deploy-config at 82%). PR / Linear / git-dirty ride the footer.

The density honesty

Your rail is 29 panes. Comfortable cards make each ~3× taller than today's row — this whole rail is a long scroll. Worth weighing: collapse idle worktrees by default, or an adaptive mode where only the selected card expands to full B and the rest stay one-line. Happy to mock either.
