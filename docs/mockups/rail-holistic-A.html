Link chips on every card

PR # and Linear chips are clickable on all cards — compact rows show them on line 1 (right of the name), expanded cards in the footer. Same chip, same hover, just relocated as the card grows. Context% stays a quiet number (not a link).

Repo = quiet label

Repos/workspaces are uppercase hairline labels, not rows — they organize without competing with the cards.

Primary session, not a worktree

A repo's same-name session is its general-purpose tabs (working on the repo directly, no dedicated worktree). It renders straight under the repo label with no ⎇ header — see periscope. Real branch worktrees (attribute-config-refactor, ci-python-rewrite) keep the ⎇ card. So ⎇ now reliably means "dedicated worktree."

Consistent collapse

Collapsed worktrees are thin cards (title bar + count + rolled-up dot), not bare floating rows.
