Iconography

◆Project / repo
solid diamond — a concrete codebase⬢ ▣
⧉Workspace
stacked planes — a hand-curated set pulled from across repos✦ ◳ ⊞
⎇Worktree / session
branch glyph — keep, it’s exactly right⑂ ⌥
◇dev (unmanaged)
hollow diamond — the catch-all scratch group⌂ ~

Why ⧉ for workspace: a repo is one place; a workspace is layers gathered from many places. The stacked-planes glyph + magenta reads “collection,” distinct from the repo diamond. Big alternatives shown on the right if you'd rather.

Both directions also fix: the floating repo rows (now labels/headers tied to their cards), collapsed worktrees (now consistent thin cards, not bare rows), and the periscope→periscope double header (flattened to one card when a repo has a single same-named worktree).
