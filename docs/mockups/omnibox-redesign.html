What changes, by direction

  • All three: live empty state (recents), open-first ordering, plain-language labels instead of glyph soup.
  • A (rich launcher): two-line rows, repo badge, branch/PR/CI chips, "● live" marker for running panes. Most polish, most new data plumbing (CI/PR status into the catalog).
  • B (scoped tabs): A's rows + a segmented Jump/New/Review filter and breadcrumb drill-in. Cuts noise; adds a mode.
  • C (minimal polish): same structure as today, just recents + icons + breadcrumb. Ships fastest, lowest ceiling.
